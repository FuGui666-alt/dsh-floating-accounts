# 1.1.1协议检测实现计划

依据[批准检测设计](<../docs/protocol-detection-spec.md>)。目标：用户不知道协议时，用主动确认后的有限同源余额GET识别现有三种协议，再明确应用；不是公网扫描或后台探测。安装1.1.0原代码和真实schema1文件保持不动，迁移仍待确认。

## 基线/必要性/边界
1.1.0默认未配置查询不猜接口合理，但无法用Key检测候选。新增只读检测Remote是必要接缝，继续唯一AccountVault/BalanceQuery，不增加新schema/依赖/网络服务。现有检测不得靠主页品牌猜单位或把error当zero。留原手动配置与旧schema1兼容，退休另次版本授权。
TDD Route: Mode=off, Decision=skipped, Strict authority=not applicable, Test posture=post-change regression。无Git仓库不建branch/commit。
