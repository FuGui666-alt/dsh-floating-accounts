## 已实现行为

1. **站点→账号→凭据三层管理**：同站多账号、账号身份备注、多模型API Key或分组密钥；只显示保存状态，不回传秘密。每账号必须显式选择所属的模型Key用于余额查询，不自动选第一个，不使用分组密钥查询。
2. **余额与Key额度分开**：Sub2API、New API token usage、DeepSeek官方balance三个明确协议。新站默认未配置，不按域名猜接口、单位或倍率。未支持的供应商仍可建档，但不能显示成余额零。
3. **只手动查询**：打开、重新载入、保存、迁移不触发查询；无轮询、自动重试或模型调用。请求仅含账号ID和revision。修改站点/账号/Key、迁移、关闭和重新载入均使迟到结果失效。
4. **DeepSeek分币种显示**：账户总额、赠金和充值金按CNY/USD分别显示，不合计；API没有提供Key额度，明确标“接口未提供”，不标无限。源十进制字符串用BigInt精确核对分项之和，不以大数浮点容差接受不一致总额。
5. **失败不造零**：接口失败、字段异常、归属不符或超时不会产生本次成功余额；已有结果仅标上次成功、非本次。
6. **显式旧数据迁移**：schema1保留查看/手动查询。必须先预览，再确认备份旧密文后升级。实例私有能力绑定完整密文摘要、文件身份、固定配置和ID映射；不匹配必须重新预览。成功返回完整备份basename，失败不承诺部分备份完整。当前revision的schema2重复迁移幂等。
7. **写入未知态保护**：所有新增写RPC与迁移发生超时/提交结果未知时禁止继续写入，必须重新载入确认；不自动重试。凭据录入成功、失败或取消后清空浏览器临时输入。
8. **传输限制保留**：公网同源HTTPS、DNS地址固定、拒绝重定向/代理/Cookie，响应大小和超时有界。不可取消DNS超时后仍保留槽到实际结束，全局最多4个在途查询、每账号1个；迟到DNS不发HTTP。
